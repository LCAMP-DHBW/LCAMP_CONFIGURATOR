# Mobiler Roboter Configurator

Ein Web-basiertes Projekt zur Darstellung eines mobilen Roboters als 3D-Modell (`.glb`) mit Farb-Vorschau auf Canvas und Export als PNG.

## Beschreibung
Dieses Projekt erlaubt:

- Laden und Anzeigen eines 3D-Roboter-Modells (`mobilerobot.glb`) 
- Live-Vorschau von Farbänderungen auf einem `<canvas>`
- Export der Farbvorschau als PNG (`mobilerobot.png`)
- Interaktion über Maus (OrbitControls)

Das Projekt ist plattformunabhängig und läuft im modernen Browser.
